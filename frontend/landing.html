The mechanism · 3 steps

How Assembly works

Capacity check → planner → temporary team → independent solve → publish → consensus (→ adversarial round if everyone agrees too fast) → debate + research → synthesis.

Section 1 · live debate interface

Watch the team cross-examine itself

Every agent publishes its position as validated JSON. A critic from a different model family attacks the strongest claim. Same-family agents count as one vote — so there's no echo chamber.

  • Independent first. Isolation enforced — no position sniffing during solve.
  • Structured dissent. supports[] / disagrees_with[] use validated agent IDs only.
  • Adversarial guard. Unanimous agreement without evidence triggers a mandatory attack round.
  • Failed rounds excluded. Crashed calls never count as "stubborn" consensus.

The diversity requirement

Independence is counted, not hoped for

Diversity is counted by model family — never by provider. The router spreads solvers across families first, forces the critic off solver families, and collapses same-family agents into a single vote.

  • ≥ 3 families — full debate, all roles filled.
  • 2 families — runs with a visible warning banner.
  • 1 family — degraded flag on the answer. No silent echo chambers.

BYOK setup · free-tier model integration

Your keys. Never ours.

Bring free-tier keys from the providers you already trust. It's private by design and free to run — no shared operator key, no billing code, no paid paths anywhere.

1

Grab free keys

Gemini via AI Studio, fast inference via Groq, long-context via OpenRouter — all free tier. Fewer than 3 live keys and the router refuses to start rather than fake it.

aistudio.google.com/apikeyconsole.groq.com/keysopenrouter.ai/keys
2

Paste & run

Keys travel in headers / body only — never URLs, never logs, never the database. Every response stores provider + model names only.

Authorization: Bearer <your-key>   # header only
provider_keys: {"groq": "***"}      # masked in logs
db rows: provider="groq" model="…"  # names only
3

Desktop locks it down

On desktop, keys live in the OS keyring (Windows Credential Manager) — never plain files, never .env. Web mode keeps them in memory for one run, then wipes.
