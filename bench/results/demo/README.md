# Demo results (SYNTHETIC — fake)

The files in this folder (`REPORT.md`, `charts/`) were generated by
`python bench/analyze.py --demo` from **synthetic demo data** (random
numbers calibrated to look realistic). They are **fake**: no real models
ran, no questions were verified, and no win rates here may be quoted.

- Do not cite any number from `demo/REPORT.md` in slides, docs, or papers.
- Real results live in `bench/results/` as `graded_*.csv` + `REPORT.md`
  written only by `bench/analyze.py` on **LIVE, VERIFIED** data
  (`DATA STATUS: LIVE, VERIFIED`). Anything else writes
  `REPORT.preview.md` with a `DEMO DATA` watermark and refuses the final
  report.
- To produce real results: verify questions with
  `python bench/verify_questions.py`, run
  `bench/run_single.py` / `run_vote.py` / `run_assembly.py` with
  `--verified-only`, grade with `bench/grade.py`, then analyze.
